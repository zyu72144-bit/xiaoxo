01 / Questions

我关注的问题

AI能力只有进入具体场景、面对真实用户并接受结果检验，才可能成为产品价值。

01 / SCENARIO

什么场景真的需要AI？

先判断问题是否成立，再讨论AI能力如何进入。

02 / TRUST

用户为什么愿意信任AI给出的结果？

产品价值不仅来自生成结果，也来自可理解、可判断和可纠正。

03 / VALUE

AI功能的价值应该如何被验证？

不止看功能是否上线，也看真实使用、结果质量与决策是否因此改善。

03 / Process

我的工作方式

把好奇变成问题，把判断变成验证，再把结果变成下一次更可靠的决策。

  1. 01

    定义问题

    先厘清用户、场景和约束，避免从一个预设功能开始。

  2. 02

    判断必要性

    确认AI是否真的必要，也检查是否存在更简单可靠的方案。

  3. 03

    最小验证

    用最小范围检验关键假设，让风险和价值尽早显现。

  4. 04

    观察反馈

    关注真实使用、信任建立和结果质量，而不只看功能完成。

  5. 05

    复盘修正

    记录判断偏差、保留有效经验，并调整下一轮行动。
